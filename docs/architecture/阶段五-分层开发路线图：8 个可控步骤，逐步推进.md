### Sprint 2：readAxisFeedbackForAxis 最小可用版（仅 X 轴，仅 D100 → Idle）
> 目标：单轴反馈的"Hello World"——一条完整链路先跑通

**生产代码**（`ModbusSystemDriver.h`）：
```cpp
void readAxisFeedbackForAxis(SystemContext& ctx, AxisId id) {
    Axis* axis = ctx.tryGetAxis(id);
    if (!axis) return;

    int16_t d100   = m_device->readInt16(regFbState(id));
    int16_t alarm  = m_device->readInt16(regFbAlarmCode(id));
    bool    absM   = m_device->readBool(regFbAbsMoving(id));
    bool    relM   = m_device->readBool(regFbRelMoving(id));
    bool    jog    = m_device->readBool(regFbJogging(id));
    float   absPos = m_device->readFloat(regFbAbsPos(id));
    float   relPos = m_device->readFloat(regFbRelPos(id));

    AxisState state = AxisStateDeriver::derive(d100, alarm, absM, relM, jog);
    // ⚠️ 注意：AxisFeedback 字段是 double，需要从 float 转换
    AxisFeedback fb{state, static_cast<double>(absPos), static_cast<double>(relPos), 0.0};
    axis->applyFeedback(fb);
}
```

### Sprint 3：补全状态推导（Error / D100=2 / Jog / Rel）
> 目标：让状态机覆盖全部枚举值

**生产代码**（`AxisStateDeriver::derive` 扩展）：
```cpp
// 现有 derive 只处理了部分状态，需要补充：
static AxisState derive(int16_t d100, int16_t alarm,
                        bool absMoving, bool relMoving, bool jogging) {
    // 优先：报警
    if (d100 == 3 || alarm != 0) return AxisState::Error;

    // 未使能
    if (d100 == 1) return AxisState::Disabled;

    // 使能后按运动信号区分
    if (d100 == 2 && !absMoving && !relMoving && !jogging) return AxisState::Idle;
    if (jogging)   return AxisState::Jogging;
    if (relMoving) return AxisState::MovingRelative;
    if (absMoving) return AxisState::MovingAbsolute;

    return AxisState::Unknown;  // 兜底
}
```

**测试**（Part2 用例 9-11，3 个测试）：
- `AlarmCodeNonZeroMeansError` — D100=1, alarm=1 → Error
- `D100State2WithoutMovementCoilMeansIdle` — D100=2, 无运动 → Idle
- `JoggingFeedbackDerivesMovingJog` — Jogging=true → MovingJog

**验证点**：每个测试一次 RED→GREEN，增量明确

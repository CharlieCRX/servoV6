# 设备控制界面 · 用户操作说明

> 适用对象：现场操作人员 / 调试人员
> 适用界面：程序启动后显示的**主控制界面**（左、中、右三栏 + 底部提醒栏）
> 说明：不同设备实际可用的轴和分组由 PLC 配置决定，界面只会显示**已启用**的轴。

---

## 一、界面总览

启动后主界面分为四个区域：

```
┌──────────────────────────────────────────────────────────────────────────┐
│  ┌───────────────┐  ┌───────────────────────────┐  ┌──────────────────┐  │
│  │               │  │                           │  │                  │  │
│  │  设备轴列表    │  │      运动数据看板          │  │    控制面板       │  │
│  │  （左栏）      │  │      （中栏）             │  │   （右栏）        │  │
│  │               │  │                           │  │                  │  │
│  │  · 选择轴      │  │  · 分组切换                │  │  · 点动/定位      │  │
│  │  · 查看状态    │  │  · 位置/状态显示            │  │  · 速度/目标设置  │  │
│  │               │  │  · 相对零点 / 限位          │  │  · 急停按钮       │  │
│  └───────────────┘  └───────────────────────────┘  └──────────────────┘  │
│  ┌──────────────────────────────────────────────────────────────────────┐ │
│  │  提醒栏（错误/告警列表，当前版本默认隐藏）                              │ │
│  └──────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

**三栏的配合关系**：先在**左栏**选中要操作的轴 → 在**中栏**查看该轴的位置与状态 → 在**右栏**进行点动或定位操作。

---

## 二、操作前必读（安全须知）

1. **先确认连接正常**：中栏顶部显示"PLC连接状态：**已连接**"（绿色灯）才能操作。显示"断连"（红色闪烁灯）时，所有运动按钮不可用，请先点击"**⟳ 重连**"。
2. **急停是最高优先级的保护**：任何异常情况下，直接按右下方的红色"**急 停**"按钮即可让设备停止。
3. **轴告警会锁定该轴**：一旦某轴出现告警，该轴的所有运动都会被禁止，必须先排除故障并清除告警（见 5.6）。
4. **点动为"按住运行、松手停止"**：千万不要点一下就走开，松手即停止。
5. **速度上限统一为 30**：输入任何速度，超过 30 都按 30 执行；单位：直线轴用 `mm/s`，旋转轴 R 用 `°/s`。

---

## 三、左栏：设备轴列表

用于**选择当前要操作的轴**。

- 列表中的每一项代表一个轴，例如"Y 轴 (水平)""Z 轴 (垂直)""R 轴 (旋转)""X 轴 (前后)""X1 轴 (物理)""X2 轴 (物理)"。
- **只显示 PLC 已启用的轴**：未启用的轴不会出现在列表中（与设备实际配置一致）。
- 每个轴项显示：
  - 轴名称；
  - 状态文字（如"待机""控制中""未绑定"）；
  - 龙门成员轴（X1/X2）在联动时会显示"受龙门控制"的提示。
- **操作方式**：直接**点击**某个轴项即可选中，被选中的轴会**高亮**（蓝色边框）。
- 点动正在进行时，为防止误切换，轴列表会被锁定、不能切换轴。

> 提示：使用无线摇杆操作时，界面会自动切换到对应轴并高亮，方便对照。

---

## 四、中栏：运动数据看板

用于**查看当前轴的实时状态**。

### 4.1 分组切换（顶部）
- 顶部有"组 [ **Machine_A / Machine_B** ] 运动数据看板"下拉框，用来切换设备分组。
- 切换分组后，左栏轴列表和右栏控制面板都会切换到对应分组。
- 切换会被锁定条件限制：急停/全局锁定时不可切换分组。

### 4.2 连接状态
- 显示"PLC连接状态：**已连接**"（绿灯）或"**断连**"（红灯闪烁）。
- 断连时会多出一个"**⟳ 重连**"按钮，点击即可尝试重新连接。

### 4.3 电机状态
- 显示当前轴的电机状态，常见文字与含义：

| 显示 | 含义 |
|------|------|
| 轴控关闭(0) | 尚未开启轴控 |
| 无动作(1) | 轴控已开，电机未上电 |
| 已上电(2) | 电机已上电、待机（**空闲可操作**） |
| 点动正向(3) | 正在正向点动 |
| 点动反向(4) | 正在反向点动 |
| 绝对定位中(5) | 正在执行绝对定位 |
| 相对定位中(6) | 正在执行相对定位 |

### 4.4 位置显示
- **绝对位置**：相对设备机械原点的位置。
- **相对位置**：相对操作员设定的"相对零点"的位置（正负带符号）。

### 4.5 相对零点操作
- **⊙ 设零**：把当前位置设定为相对零点。
- **⊗ 清除**：清除已设置的相对零点。
- 设置过相对零点后，会多显示一行"零点: xxx"用于查看。

### 4.6 行程限位
- 底部有一条**行程进度条**，蓝色条表示当前位置在行程中的比例，白色竖线是当前位置指针。
- 下方显示"负限位 / 正限位"数值；未启用的一侧显示为 `-∞ / ＋∞`。
- 当触发限位时：
  - 出现黄色**闪烁限位灯**，并提示"限位触发：正软限位/负软限位/正硬限位/负硬限位"；
  - 同时给出撤离方向提示"**仅可正向撤离**"或"**仅可反向撤离**"；
  - 此时**定位功能被锁定**（右栏定位模式的"🔒"标记），只能用点动把轴撤离限位区。
- R 轴（旋转轴）不显示行程进度条。

## 五、右栏：控制面板

用于**实际操作设备**。

### 5.1 状态横幅（从上到下，出现时才会显示）
- **红色急停横幅**：显示急停状态，处于急停时闪烁。
- **红色轴告警横幅**：显示"⚠️ 轴告警 (0x…) 已锁定运动，请确认后清除"。点击该横幅可打开告警处理弹窗。
- **棕色龙门锁定横幅**：显示"🔒 受龙门控制"，表示当前轴被龙门联动占用，不能单独操作。

### 5.2 模式切换：点动 / 定位
- 面板顶部有两段式切换：**点动** 与 **定位**。
- **点动**：用于手动微调。
- **定位**：用于按目标值自动运动。
- 到达限位时，"定位"会被锁定（显示 🔒），只能使用"点动"。

### 5.3 点动模式（手动微调）
1. 点击"**点动速度: xx.x mm/s ⚙️**"旁的 ⚙️，用弹出的**数字键盘**输入速度（上限 30），按"确认"。
2. **按住**"**前进 +**"按钮 → 轴正向移动；**松开** → 停止。
3. **按住**"**后退 -**"按钮 → 轴反向移动；**松开** → 停止。
4. 移动过程中，对应方向按钮会保持高亮；若由摇杆/UDP 等方式触发的运动，按钮也会同步高亮（反映真实状态）。

### 5.4 定位模式（自动运动到目标）
1. 点击"**定位速度: xx.x mm/s ⚙️**"旁的 ⚙️，设置定位速度。
2. 用"**绝对 / 相对**"切换器选择定位方式：
   - **绝对**：输入"**目标:**"位置（相对机械原点的绝对坐标）；
   - **相对**：输入"**距离:**"（相对当前位置要移动的量，带正负）。
   - 点击目标/距离旁的 ⚙️ 用数字键盘输入数值。
3. 点击底部"**绝对定位**"或"**相对定位**"按钮执行。
4. 定位运行中，按钮会显示"运行中…"，期间其他普通操作被锁定，直到运动结束。
5. 若设置的目标被拒绝（例如超出限位），会弹出"⚠️ 设置失败"提示，请修改后重试。

### 5.5 急停按钮（面板最下方）
- 正常状态显示红色"**急 停**"：按下即触发急停，设备立即停止。
- 已触发急停后显示"**解除急停**"：在**确认现场安全**后点击可解除。
- 急停按钮在任何情况下都可操作，不受其他锁定限制。

### 5.6 轴告警处理
- 当某轴出现告警时，会自动弹出"⚠️ **轴告警**"窗口，显示告警码 0x…。
- **告警会禁止该轴所有运动**（点动/定位）。
- 处理步骤：
  1. 确认并排除现场故障；
  2. 在弹窗中点击"**确认清除告警**"（该操作会向 PLC 发送清除信号，请务必在故障排除后再执行）；
  3. 告警清除后，运动功能恢复。
- 也可以点击红色告警横幅重新打开该弹窗。

## 六、常用操作速查

### 6.1 点动移动某个轴
选中轴 → 切到"点动" → ⚙️设速度 → **按住**"前进+/后退-"移动 → 到达位置后**松手**。

### 6.2 定位到指定位置（绝对）
选中轴 → 切到"定位" → ⚙️设定位速度 → 选"绝对" → ⚙️输入目标值 → 点击"绝对定位"。

### 6.3 从当前位置移动一段距离（相对）
选中轴 → 切到"定位" → ⚙️设定位速度 → 选"相对" → ⚙️输入距离（带正负）→ 点击"相对定位"。

### 6.4 设置/清除相对零点
中栏相对位置行 → 点击"**⊙ 设零**"（设定）或"**⊗ 清除**"（清除）。

### 6.5 触发/解除急停
右栏底部红色按钮：未急停时按"急 停"，已急停时按"解除急停"。

### 6.6 切换分组
中栏顶部下拉框选择 Machine_A / Machine_B。

### 6.7 断线重连
中栏显示"断连"时，点击"**⟳ 重连**"。

## 七、为什么按钮是灰的（点不动）？

运动类按钮（点动、定位、设置目标等）**变灰是正常的保护机制**，说明当前不满足操作条件。常见原因：

| 现象 | 可能原因 | 处理办法 |
|------|---------|---------|
| 所有运动按钮变灰 | PLC 未连接 | 等待连接或点"⟳ 重连" |
| 所有运动按钮变灰 | 处于急停状态 / 全局锁定 | 解除急停，确认系统锁定指示灯熄灭 |
| 所有运动按钮变灰 | 反馈数据不可信（通讯质量差） | 检查通讯，等待状态恢复 |
| 定位按钮变灰、显示 🔒 | 轴已触发限位 | 用点动沿提示方向撤离限位区 |
| 轴项不显示 / 显示"未绑定" | 该轴未被 PLC 启用 | 属正常（与设备配置一致） |
| 点动按钮变灰 | 轴正被摇杆、上位机（UDP）等其他来源占用 | 等待对方释放后再操作 |
| 定位/设置按钮变灰 | 轴正在运动中（点动或定位中） | 等待运动结束，或按停止 |
| 出现"🔒 受龙门控制" | X1/X2 处于龙门联动状态 | 需按龙门操作流程处理，不能单独点动该轴 |

> 原则：**停止、急停、解除急停**这三类操作不受上述普通锁定限制，始终可以执行。

## 八、指示灯颜色含义

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 就绪 / 正常 / 已连接 / 空闲 |
| 🔵 蓝色 | 运行中 / 运动中 |
| ⚪ 灰色 | 掉电 / 禁用 / 未使能 |
| 🔴 红色 | 报警 / 断连 / 急停 |
| 🟡 黄色 | 警告 / 限位触发 |

## 九、常见问题（FAQ）

**Q1：界面上看不到某个轴，是坏了吗？**
不是。界面只显示 PLC 已启用的轴；未启用的轴不会显示。

**Q2：我输入的速度超过 30，会怎样？**
界面会自动按 **30** 处理（超过上限一律按上限），并以此下发，不会报错。

**Q3：点动按钮点一下没反应？**
点动是"**按住运行、松手停止**"，需要**按住不放**才能持续移动。

**Q4：定位按钮点了显示"不可用"？**
说明当前不满足定位条件，常见于：轴在运动、触发限位、急停/锁定、或连接异常。

**Q5：为什么某个轴一直点不动？**
请依次检查：连接是否正常 → 是否处于急停 → 该轴是否有告警（红色横幅）→ 是否被龙门占用或被他方（摇杆/UDP）占用。

**Q6：X1/X2 显示"受龙门控制"是什么意思？**
表示这两个轴已组成龙门联动，由系统统一控制，不能单独点动，需通过龙门操作流程处理。

**Q7：急停后怎么恢复？**
确认现场安全后，点击右栏底部的"**解除急停**"按钮即可尝试解除。

## 十、术语说明

| 术语 | 说明 |
|------|------|
| 点动（Jog） | 按住按钮持续移动、松手即停的手动操作方式 |
| 定位（Positioning） | 设定目标后自动运动到该位置 |
| 绝对定位 | 目标以机械原点为基准的绝对坐标 |
| 相对定位 | 目标以当前位置为起点的位移量 |
| 相对零点 | 操作员自定义的位置基准 |
| 使能 / 上电 | 电机上电进入可运动状态 |
| 龙门（Gantry） | 两轴同步驱动的结构（对应 X1/X2） |
| 限位 | 防止机械超程的保护边界（软限位/硬限位） |
| 全局锁定 | 系统级禁止普通运动的保护状态 |
